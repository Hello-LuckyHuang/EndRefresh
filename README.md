# 末地刷新Mod

> 本模组为作者突发奇想，想让末地外岛像周本一样刷新的产物。代码完全由ChatGPT 5.5编写。

## 支持版本
Minecraft 1.21.1 NeoForge

## 模组功能
- 模组实现末地的定期区块清理功能。通过删除.mca中的区块数据实现。玩家附近的区块、已经加载在服务器中的区块、保护范围内的主岛区块不会被删除。
- 可使用`/endrefresh cleanup`直接开始一次区块清除任务。
- 更改了箱子战利品生成代码，为了每次刷新后都能有独特的战利品搜索体验，生成的战利品不再随箱子固定。未测试是否与Lootr兼容。可通过配置文件关闭此功能
- 可通过配置文件配置不清理区块范围（默认区块坐标[-30, 30]）、清理间隔（默认7天）
- **此模组仅作功能示例，不发布正式版，不维护bug**
